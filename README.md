# 사랑해 하트 ❤️

20개 언어의 "사랑해"가 한 글자씩 채워지면서 빨간 하트가 만들어지고,
하트가 다 채워지면 가운데에 네모칸이 생기면서 내가 쓴 메시지가 한 글자씩 나타나는 페이지입니다.

## 실행 방법

1. `index.html` 파일을 더블클릭합니다.
2. 브라우저(크롬, 엣지, 사파리 등)에서 바로 실행됩니다.

설치할 것도, 인터넷 연결도 필요 없습니다.

## 메시지 바꾸기

1. `index.html`을 메모장이나 VS Code 같은 편집기로 엽니다.
2. 아래 줄을 찾습니다 (24번째 줄쯤).

   ```js
   const MESSAGE = ["insert your message here"];
   ```

3. 따옴표 안의 글을 원하는 메시지로 바꿉니다. 한 줄씩 따로 따옴표로 묶고, 쉼표로 구분하면 여러 줄로 나옵니다.

   ```js
   const MESSAGE = ["은혜야", "마니마니 사랑해"];   // 두 줄로 나옴
   ```

4. 저장한 뒤 브라우저에서 새로고침(F5)하면 바뀐 메시지가 나옵니다.

> 메시지가 길수록 글씨가 작아집니다. 한 줄은 짧게, 2~3줄 정도가 가장 예쁘게 보입니다.

## 그 밖에 바꿀 수 있는 것

| 바꾸고 싶은 것 | 찾을 줄 | 설명 |
|---|---|---|
| 속도 | `const SPEED_MS = 60;` | 숫자가 작을수록 빨라집니다. 메시지는 하트보다 4배 느리게 나옵니다. |
| 하트를 채우는 말 | `const LOVE = [ ... ];` | `["언어 이름", "문장"]` 형식으로 추가하거나 지울 수 있습니다. |

## 참고

- 화면 아래에는 지금 채워지고 있는 언어와 문장이 표시됩니다.
- 창 크기를 바꾸면 하트도 화면에 맞게 다시 그려집니다.
- 휴대폰으로 보려면 파일을 휴대폰에 보내서 브라우저로 열면 됩니다.
